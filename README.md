# Just Floaty

Just Floaty is a small creative character project built around a hand-drawn
capybara character, internally nicknamed "Floaty."

The first product is a very small public website (justfloaty.com): one quiet,
mostly empty page with a single illustration of Floaty, a loading bar
permanently stuck at 87%, and the text "Still floating." No menus, no
marketing copy, no animation — intentionally understated and handmade.

## Status

Version 1 is in progress. Currently a minimal technical foundation
(`index.html` and `css/style.css`) with no final visual design and no
artwork added yet.
